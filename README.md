One line of weather for the invented city of Gloomburg, written for make.fun's "Charm the Commuter: Forecast a City That Isn't" bounty: drizzle all day, a late bus, pigeons with umbrellas — and a nudge to the bored commuter at the bus stop to carry one too.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

This writes the forecast (135 characters) to `out/entry.txt`.
